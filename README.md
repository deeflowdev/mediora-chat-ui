# 🩺 Mediora AI – Medical Chat Interface

A frontend-based medical assistant chat interface designed to simulate an AI-powered healthcare support experience with a focus on clean UI, conversational flow, and document handling.

---

## Overview
Mediora AI allows users to interact through a chat-based interface and upload supporting medical documents such as images and PDFs. The project is built with a frontend that is connected to a separate Flask backend (not included in this repository).

---

## Features
- Chat-based user interface  
- Upload support for images and PDFs  
- Basic authentication using localStorage  
- Responsive and clean UI design  
- Prepared for backend API integration  

---

## Tech Stack
- HTML  
- CSS  
- JavaScript  
- Flask (backend developed separately, not included here)

---

## Status
Frontend completed. Backend exists separately but is not part of this repository.
